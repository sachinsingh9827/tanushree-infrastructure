# Tanushree Infrastructure Frontend

React and Vite frontend for the Tanushree Infrastructure website and admin panel.

## Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Set `VITE_API_URL` in `.env` to the backend API base URL, for example `http://localhost:5001/api` for local development. In the frontend Vercel project, set it to `https://tanushree-infrastructure-backend.vercel.app/api`.

## Build

```bash
npm run build
```
